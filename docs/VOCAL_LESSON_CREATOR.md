# Vocal Lesson Creator

## Overview

The `combine_mp3.py` script combines MP3 audio files from the `sounds/` folder into a single audio lesson file. It is designed to build structured Portuguese vocabulary lessons by chaining word pronunciations and their example sentences.

## Setup

**Requirements:** Python 3.10+, `pydub`, and `ffmpeg`.

```bash
# Install ffmpeg (Debian/Ubuntu)
sudo apt-get update && sudo apt-get install -y ffmpeg

# Install Python dependency
pip install -r vocal_lesson_creator/requirements.txt
```

## Usage

Run from the `vocal_lesson_creator/` directory:

```bash
cd vocal_lesson_creator
```

### Mode 1 — By challenge UUID (recommended)

Looks up `sounds/{uuid}.mp3` (Portuguese pronunciation) and automatically includes the example sentence files for the chosen language.

```bash
python combine_mp3.py --ids <uuid1> <uuid2> ... [--lang en|fr] [--output lesson.mp3]
```

**Example:**
```bash
python combine_mp3.py \
  --ids 48348b0d-cf1d-44f5-8252-e460884dd22c c5f6... \
  --lang fr \
  --output lesson_basics.mp3
```

For each UUID this includes, in order:
1. `{uuid}_{lang}_translation.mp3` — the translation, spoken in the learner's language first so they can try to recall the word
2. `{uuid}.mp3` — Portuguese word pronunciation
3. `{uuid}_{lang}_exemple.mp3` — monolingual example in the learner's language
4. `{uuid}_{lang}_pt_exemple.mp3` — bilingual (lang + Portuguese) example

Steps 3 and 4 are skipped when the files are missing.

### Mode 2 — From a list file

Create a plain text file with one UUID or `.mp3` path per line. Lines starting with `#` are ignored.

```bash
python combine_mp3.py --file lesson.txt [--lang en|fr] [--output lesson.mp3]
```

**Example `lesson.txt`:**
```
# Greetings
48348b0d-cf1d-44f5-8252-e460884dd22c
c5f6a7b8-c9d0-1234-0123-456789012345

# Direct file paths also work
../sounds/some-intro.mp3
```

### Mode 3 — Explicit file list

```bash
python combine_mp3.py --files ../sounds/abc.mp3 ../sounds/def.mp3 --output out.mp3
```

### Mode 4 — Weekly challenge (MongoDB, used in production)

Builds one lesson per `weeklychallenges` document found in the last two weeks. Each lesson uses the
owner's `preferredLanguage`, so a French-speaking user gets French translations and an English
speaker gets English ones. Guests and deleted users are skipped.

```bash
python combine_mp3.py --weekly-challenge --lang fr --output-dir /weekly-audio
```

Requires `MONGODB_URI`. For every generated lesson it writes to the document:

```json
"audio": {
  "filename": "weekly_<docId>_20261026_040000.mp3",
  "last_update": "2026-10-26",
  "mp4": true,
  "duration_s": 1234.5,
  "size_bytes": 24680123
}
```

`duration_s` and `size_bytes` exist for the podcast feed (`<itunes:duration>` and the enclosure
`length`) — see [PODCAST.md](PODCAST.md). With `--force` a lesson is rebuilt even if it was already
generated today; MP4 generation is skipped by default because it is only needed for YouTube.

## Options

| Option | Default | Description |
|---|---|---|
| `--ids UUID ...` | — | Challenge UUIDs to combine |
| `--file FILE` | — | Text file with one UUID or `.mp3` path per line |
| `--files PATH ...` | — | Explicit MP3 paths |
| `--weekly-challenge` | off | Mongo-driven mode: one lesson per `weeklychallenges` document |
| `--lang en\|fr` | `en` | Language for translations/examples (fallback only in weekly mode) |
| `--no-examples` | off | Include only the translation and the Portuguese pronunciation |
| `--pause MS` | `2000` | Silence inserted between challenges |
| `--output FILE` | `lesson.mp3` | Output filename (saved in `vocal_lesson_creator/output/`) |
| `--output-dir DIR` | `vocal_lesson_creator/output` | Output directory (Helm overrides it to `/weekly-audio`) |
| `--sounds-dir DIR` | `../sounds` (`/sounds` in Docker) | Source directory for pronunciation clips |
| `--no-mp4` | off | Skip MP4 generation in weekly mode |
| `--force` | off | Rebuild even if today's lesson already exists |
| `--log-level LEVEL` | `INFO` | `DEBUG`, `INFO`, `WARNING` or `ERROR` |

## Output

Lessons are saved to `vocal_lesson_creator/output/` in manual modes and to `--output-dir` in weekly
mode. The directory is created automatically. In production the Helm CronJob writes them to
`/weekly-audio`, where they are served at `https://dialecthub.net/weekly-audio/` and consumed by
the YouTube uploader and the podcast feed.

## Audio File Naming Convention

Files in `sounds/` follow this pattern:

| Filename pattern | Content |
|---|---|
| `{uuid}.mp3` | Portuguese word pronunciation |
| `{uuid}_en_exemple.mp3` | English example sentence |
| `{uuid}_en_pt_exemple.mp3` | English + Portuguese bilingual example |
| `{uuid}_fr_exemple.mp3` | French example sentence |
| `{uuid}_fr_pt_exemple.mp3` | French + Portuguese bilingual example |

These are generated by `data/TextToSpeechGenerator.py`. See [AUDIO_GENERATION.md](AUDIO_GENERATION.md) for details.
