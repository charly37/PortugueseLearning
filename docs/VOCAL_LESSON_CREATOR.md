# Vocal Lesson Creator

## Overview

The `combine_mp3.py` script combines MP3 audio files from the `sounds/` folder into a single audio lesson file. It is designed to build structured Portuguese vocabulary lessons by chaining word pronunciations and their example sentences.

## Setup

**Requirements:** Python 3.10+, `pydub`, and `ffmpeg`.

```bash
# Install ffmpeg (Debian/Ubuntu)
sudo apt-get update && sudo apt-get install -y ffmpeg

# Install Python dependency
pip install -r vocal_lesson_creator/requirements.txt
```

## Usage

Run from the `vocal_lesson_creator/` directory:

```bash
cd vocal_lesson_creator
```

### Mode 1 — By challenge UUID (recommended)

Looks up `sounds/{uuid}.mp3` (Portuguese pronunciation) and automatically includes the example sentence files for the chosen language.

```bash
python combine_mp3.py --ids <uuid1> <uuid2> ... [--lang en|fr] [--output lesson.mp3]
```

**Example:**
```bash
python combine_mp3.py \
  --ids 48348b0d-cf1d-44f5-8252-e460884dd22c c5f6... \
  --lang fr \
  --output lesson_basics.mp3
```

For each UUID this includes, in order:
1. `{uuid}.mp3` — Portuguese word pronunciation
2. `{uuid}_{lang}_exemple.mp3` — translation example in the chosen language
3. `{uuid}_{lang}_pt_exemple.mp3` — bilingual (lang + Portuguese) example

### Mode 2 — From a list file

Create a plain text file with one UUID or `.mp3` path per line. Lines starting with `#` are ignored.

```bash
python combine_mp3.py --file lesson.txt [--lang en|fr] [--output lesson.mp3]
```

**Example `lesson.txt`:**
```
# Greetings
48348b0d-cf1d-44f5-8252-e460884dd22c
c5f6a7b8-c9d0-1234-0123-456789012345

# Direct file paths also work
../sounds/some-intro.mp3
```

### Mode 3 — Explicit file list

```bash
python combine_mp3.py --files ../sounds/abc.mp3 ../sounds/def.mp3 --output out.mp3
```

## Options

| Option | Default | Description |
|---|---|---|
| `--lang en\|fr` | `en` | Language for examples (used with `--ids` / `--file`) |
| `--no-examples` | off | Include only the Portuguese pronunciation, skip example sentences |
| `--pause MS` | `800` | Milliseconds of silence inserted between clips |
| `--output FILE` | `lesson.mp3` | Output filename (saved in `vocal_lesson_creator/output/`) |

## Output

Lessons are saved to `vocal_lesson_creator/output/`. The directory is created automatically.

## Audio File Naming Convention

Files in `sounds/` follow this pattern:

| Filename pattern | Content |
|---|---|
| `{uuid}.mp3` | Portuguese word pronunciation |
| `{uuid}_en_exemple.mp3` | English example sentence |
| `{uuid}_en_pt_exemple.mp3` | English + Portuguese bilingual example |
| `{uuid}_fr_exemple.mp3` | French example sentence |
| `{uuid}_fr_pt_exemple.mp3` | French + Portuguese bilingual example |

These are generated by `data/TextToSpeechGenerator.py`. See [AUDIO_GENERATION.md](AUDIO_GENERATION.md) for details.
